# seoul_rent_api — 서울 전월세 가격 분석

서울 열린데이터광장 **「서울시 부동산 전월세가 정보」(tbLnOpendataRentV)** API에서 데이터를 실시간으로 불러와,
자치구·법정동별 **2022–2026년** 전세·월세 가격 변화를 분석하는 웹앱입니다. Cloudflare Pages로 배포합니다.

- 배포 주소: https://seoul-rent-snusun.pages.dev
- 디자인: 밝은 배경 + 민트 포인트 컬러, 단순한 단일 페이지

## 기능

1. **지도에서 법정동 선택**: 서울 467개 법정동 경계 지도에서 동을 클릭하면 바로 분석합니다. 자치구·법정동 드롭다운으로도 고를 수 있으며, 지도와 드롭다운은 서로 동기화됩니다.
2. 선택한 동의 **2022·2023·2024·2025·2026년 데이터를 모두** API로 요청합니다. 연도별로 병렬 호출하고, 1,000건 단위 페이지는 자동으로 처리합니다.
3. **공공임대 별도 구분**: 행복주택·국민임대·영구임대·장기전세·LH/SH 단지·역세권청년주택 등은 ‘아파트’ 등에 포함하지 않고 ‘공공임대’ 용도로 따로 분류합니다.
4. **전세환산 보증금**(전환율 5%): `보증금 + 월세 × 12 ÷ 0.05`로 모든 거래를 전세 기준 금액으로 환산합니다. 월별 추이 그래프(전체 거래 / 월세 거래만)와 연도별 요약표에 표시합니다.
5. **첫 화면: 자치구 전세환산 보증금 TOP 10**: 유형별(아파트/연립다세대/오피스텔/단독다가구/공공임대) 순위입니다. 총액과 ㎡당을 전환할 수 있고, 자치구를 누르면 지도에서 보여 줍니다.
6. 핵심 지표: 총 거래 건수, 전세 보증금 중위값, ㎡당 전세 보증금, 월세 중위값. 모두 최근 12개월과 직전 12개월을 비교합니다.
7. 차트: 월별 전세 보증금 중위값(보증금/㎡당 전환), 월별 전세·월세 거래 건수, 월별 월세 중위값.
8. 연도별 요약표, 최근 거래 내역(건물명 검색), 건물 용도 필터(아파트/연립다세대/오피스텔/단독다가구/공공임대), CSV 다운로드.
9. `?gu=11680&dong=10300` 형태의 링크로 특정 동을 바로 열 수 있습니다.

## API 키 보안

- API 키는 **저장소에 포함되지 않습니다.** `.env`, `.dev.vars`는 `.gitignore`로 제외됩니다.
- 배포 환경에서는 **Cloudflare Pages Secret**(`SEOUL_API_KEY`)으로만 저장되며, 서버 함수 안에서만 사용됩니다. 브라우저는 키를 볼 수 없습니다.
- 서버 함수는 입력값을 화이트리스트로 검증합니다(5자리 숫자 코드, 2022–2026년). 따라서 임의의 서울시 API 호출에 악용될 수 없습니다.
- 다른 사이트에서 오는 요청(`Sec-Fetch-Site: cross-site`)은 차단합니다. GET 요청만 허용합니다.
- 오류 메시지에 업스트림 URL(키 포함)을 노출하지 않습니다. 결과는 엣지 캐시에 6시간 저장합니다.
- CSP, X-Frame-Options 등 보안 헤더를 적용합니다. 지도 배경 타일을 쓰지 않아 브라우저에 외부 지도 API 키가 필요 없습니다.

## 실행 / 배포

```bash
npm install
# 로컬: .dev.vars 파일에 키 저장 (커밋 금지)
echo "SEOUL_API_KEY=발급받은키" > .dev.vars
npm run dev

# 배포
npx wrangler login
npx wrangler pages project create seoul-rent-snusun --production-branch main   # 최초 1회
npx wrangler pages secret put SEOUL_API_KEY --project-name seoul-rent-snusun   # 프롬프트에 키 입력
npm run deploy
```

### TOP 10 데이터 갱신

서울 전체 최근 12개월 데이터(약 150만 건 조회, 서울 API 약 1,500회 호출, 8분 내외)를 동별 조회처럼 방문자마다 실시간으로 받을 수는 없습니다. 그래서 스크립트로 미리 집계해 `public/top10.json`에 저장합니다.

```bash
python3 scripts/build_top10.py   # .dev.vars 또는 ../.env의 SEOUL_API_KEY 사용
npm run deploy
```

- 기간: 계약일 기준 최근 12개월. 집계 중인 마지막 달은 제외합니다.
- 지표: 자치구·유형별 전세환산 보증금 중위값(총액, ㎡당). 거래 30건 미만인 자치구는 제외합니다.

## 데이터 유의사항

- 서울시 API는 현재 **접수연도(RCPT_YR) 2024–2026년**만 제공합니다. 2022·2023년을 요청하면 “해당하는 데이터가 없습니다”가 반환됩니다. 앱은 다섯 해를 모두 요청하고, 실제로 받은 데이터를 분석합니다. 계약일 기준으로는 2023년 하반기 계약 일부(2024년 신고분)부터 포함되며, 이 해는 표에서 `부분`으로 표시됩니다.
- 이 데이터셋은 행정동이 아니라 **법정동** 단위로 제공되므로 법정동으로 선택합니다.
- **공공임대 판별**: 데이터에 공공임대 여부 항목이 없어 건물명으로 판별합니다.
  - 모든 용도: `행복주택`, `행복아파트`, `임대`, `장기전세`, `휴먼시아`, `도시개발공사`, `청년주택`, `공공주택`
  - 아파트만: `LH`, `엘에이치`, `SH`, `에스에이치` (빌딩·빌라 이름 오탐 방지)
  - 이름에 표시가 없는 공공임대는 누락될 수 있습니다.
- 가격은 중위값입니다. 월 거래가 3건 미만인 달은 그래프에서 생략합니다. 금액 단위는 만원입니다.
